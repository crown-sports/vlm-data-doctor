# Different pages, one source document

[简体中文](README.zh-CN.md)

Unique records and images can still violate a document-disjoint evaluation policy.
These pages are generated by `examples/generate.py` to demonstrate checks, not to evaluate a model.

| File | Content | `document_id` |
| --- | --- | --- |
| `train.jsonl` | Manual A, page 1: ask for the owner | `manual-a` |
| `validation.jsonl` | Manual A, page 2: ask for the review interval | `manual-a` |
| `validation-disjoint.jsonl` | Manual B, page 1: ask for the owner | `manual-b` |

Install the package, then run these commands from the repository root.

## 1. Default checks pass

```bash
vlm-data-doctor check examples/document-split/train.jsonl --eval examples/document-split/validation.jsonl
```

Expect `Errors: 0 | Warnings: 0` and exit `0`. Image bytes, questions and answers differ.

## 2. Enforce a document-disjoint policy

```bash
vlm-data-doctor check examples/document-split/train.jsonl --eval examples/document-split/validation.jsonl --group-key document_id
```

```text
VLM Data Doctor
Records: train=1, eval=1
Unique image files: 2
Errors: 1 | Warnings: 0
ERROR split_group_overlap eval:1 document_id: The selected group also appears at train:1; use a group-disjoint split.
```

Exit `1` is expected here. If evaluation targets unseen documents, both pages of A
belong in the same split.

## 3. Evaluate on a separate document

```bash
vlm-data-doctor check examples/document-split/train.jsonl --eval examples/document-split/validation-disjoint.jsonl --group-key document_id --strict
```

Expect `Errors: 0 | Warnings: 0` and exit `0`. Evaluation now uses manual B.
This example swaps an evaluation file. For real data, assign source documents to
splits before generating pages and questions. Do not change IDs to hide overlap.

To inspect the finding visually, append `--format html --output document-split.html`
to step 2. Open the report in a browser. The output file must not already exist;
the command still exits `1`.

## What this establishes

The policy checks supplied IDs, not document content or provenance. A task asking
new questions about known documents may legitimately use another split policy.
This example makes no claim about the model-score effect of changing the split.

## Generate the split instead of repairing one by hand

```bash
vlm-data-doctor split examples/document-split/all.jsonl --group-key document_id --seed 42 --output /tmp/manual-split
vlm-data-doctor check /tmp/manual-split/train.jsonl --eval /tmp/manual-split/eval.jsonl --image-root examples/document-split --group-key document_id --strict
```

Use a new output directory each time. `all.jsonl` combines the three existing
fixture records. Both pages of manual A stay together; manual B goes to the other
split. The manifest lists original source rows and file hashes. Images remain in
this example directory, so the explicit image root is required after export.
